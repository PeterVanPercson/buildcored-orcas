# Submitting your daily ship

One project a day. Miss a day and you're out. The mechanics:

1. Public repo, one per project, named after the build.
2. README with three lines: what it does, how to run it, what you'd do with a second day.
3. Post the repo link in the cohort channel **before midnight your time**.
4. Day number in the message ("Day 12 — SnapAnnotator").

The showcase pulls straight from the project DB, so a clean README is what
strangers will read at https://buildcored.com/projects/. Questions → the
Q&A discussions on this repo.
